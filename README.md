# python-card-validator
A beginner Python CLI project that validates card numbers using the Luhn algorithm and identifies card types.

My first-ever Python project! 

This is a command-line card validator built with Python. It uses the Luhn Algorithm to check whether a card number passes the mathematical validation test and attempts to identify the card type based on its number pattern.

##  Features

-  Validates card numbers using the Luhn Algorithm
- 💳 Identifies supported card types
- 🔢 Checks whether the user entered numbers correctly
- ⚠️ Handles invalid input
- Runs directly in the command line

## 🛠️ Technologies Used

- Python 3
- Luhn Algorithm
- Command Line Interface (CLI)
